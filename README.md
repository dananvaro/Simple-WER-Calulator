# Simple WER Calculator

Simple WER script, needs manually change the input. 

## Requirements

- Python
- jiwer

Install jiwer:

```bash
pip install jiwer
```

## Setup

Clone the repository:

```bash
git clone https://github.com/dananvaro/Simple-WER-Calulator.git
cd Simple-WER-Calulator
```

Run the script:

```bash
python WER-Calculator.py
```
